# 🎓 CSE Class Portal (MERN Stack)

A complete academic portal built using the **MERN Stack (MongoDB, Express, React, Node.js)** designed specifically for CSE students. This portal allows students to upload participation certificates, apply for leave, calculate GPA, and gives admins tools to manage users and submissions efficiently.

---

## 🌟 Features

### 👨‍🎓 Student
- 🔐 Secure login with pre-registered credentials
- 📤 Upload certificates (PDF format) semester-wise to Cloudinary
- 📝 Submit leave requests including leave type, duration, and reason
- 🧮 GPA Calculator to compute semester-wise GPA based on subjects, credits, and grades

### 🧑‍💼 Admin
- 🔐 Admin login access
- ➕ Add new students with name, email, and password
- 👥 View list of all students
- 📄 View each student's submitted certificates and leave requests

---

## 🧮 GPA Calculator (New Feature)

This tool allows students to calculate their GPA using a clean and intuitive interface.

**Features:**
- Dynamic form with the ability to add/remove subjects
- Input fields for subject name, credit hours, and grade
- Auto-calculation of GPA based on entered values
- Instant display of results on the same page
